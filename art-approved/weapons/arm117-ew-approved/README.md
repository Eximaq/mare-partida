# Braço 117: laterais aprovadas

Aprovados em 2026-11-12 após apresentação dos ciclos EAST/WEST masculino e feminino com quatro trajes. Dois backups exatos, 20.539.297 bytes no total.

Para verificar: `python3 RESTORE.py --verify-only`. Para recompor os ZIPs: `python3 RESTORE.py --output restored`. As reconstruções foram executadas e comparadas byte a byte aos originais; CRC e SHA-256 também foram verificados. O manifesto contém os hashes individuais.

Os documentos internos dos ZIPs foram preservados como histórico de produção; este registro documenta a aprovação posterior. Contagens PNG incluem camadas e não equivalem a poses únicas. Arquivo de fontes e QA, sem PR, merge, ativação ou teste no jogo.
