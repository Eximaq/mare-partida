# Nautical raster material library

Original artwork generated with the built-in ImageGen tool, using the owner-provided reference as material direction. No reference-sheet pixels, labels or sample numerals are distributed. No PixelLab generation was used. The tool did not report a monetary cost.

The accepted atlas was 1254×1254. `tools/prepare_nautical_assets.py` uses inspected, explicit cell bounds; it extracts, resizes and encodes WebP, without drawing substitute artwork. It also records source SHA-256, crop bounds, dimensions and byte sizes in `manifest.json`. Keep the source atlas outside the distributed repository. Run the script only against that inspected source; a different output needs newly measured bounds.

Frames use a 44px nine-slice; the final CSS controls the on-screen rim width. Panel centers tile separately. Button artwork is sliced with its center filled. Status values and percentages are live game content; none is baked into the artwork.

## Final ImageGen prompt

Use case: stylized-concept. Asset type: production raster GUI asset atlas for a browser pirate nautical 2D RPG, NOT a mockup or presentation. Create one square 1536x1536 image arranged in EXACTLY four equal columns and four equal rows, each 384x384 square tile filling its own cell edge to edge. NO gaps, labels, words, letters, numbers, watermarks or grid lines. Use the attached image ONLY for material style: detailed crisp pixel art aged naval timber, antique brass, dark petrol blue, sparse rope. Each tile is an independently useful resizable nine-slice square panel (buttons will be resized by nine slicing, NOT flattened image scaling). Every frame must touch the four edges of its own tile, square corners, narrow rim occupying 24px from edges, a small bronze ornamental bracket at each corner within 40px. No symbols in panel centers; centers are calm textures for live game text. Uniform frontal flat orthographic view. Exact row/column content: row 1 col1 ornate antique bronze and dark wood frame surrounding very dark teal subtle textured center; row1 col2 simpler thin aged brass frame surrounding nearly black petrol textured center; row1 col3 brass frame surrounding pale warm parchment textured center; row1 col4 dark weathered timber texture only, no border, no frame. Row2 col1 button normal: brass riveted frame with dark brown timber center; row2 col2 button hover: brighter gold rim and lighter brown timber; row2 col3 button pressed: recessed dark wood and subdued brass rim; row2 col4 button selected: bright brass rim with deep green-blue enameled center. Row3 col1 disabled button: muted gray aged steel rim and gray wood center; row3 col2 keyboard focus button: luminous ivory-brass rim with dark wood center; row3 col3 inventory empty square slot: simple dark brass/wood narrow rim, very dark brown recessed center; row3 col4 textured header panel: brass rim, long horizontal wood grain in dark naval timber center with sparse rope only at corner edges. Row4 col1 empty meter track: aged bronze thin rim surrounding nearly black petrol center, corner rivets; row4 col2 unframed vivid ruby RED glass liquid fill texture full-bleed, bright top highlight fading to dark red bottom, fine pixel detail; row4 col3 unframed saturated cyan BLUE ocean liquid fill texture full-bleed, bright top highlight and deep blue bottom; row4 col4 unframed GOLD AMBER glowing liquid fill texture full-bleed, bright top highlight and dark honey bottom. IMPORTANT: all 16 cells must remain precisely square, axis aligned, identical size with edges at multiples of 384; no extra decorative objects overlapping cells. No text or numerals anywhere. Rich hand painted pixel art material quality, clear small-size details. Palette petrol #102C38 navy #10202D timber #49301F bronze #A77A3D gold #D8B575 parchment #E6D4AB.

Requested size was guidance to ImageGen; the actual returned dimensions and irregular row boundaries were inspected rather than assumed. The final WebPs are at most 256px per side.
