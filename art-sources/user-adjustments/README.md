# Fontes e ajustes fornecidos pelo usuário

Arquivo técnico separado de `art-approved`. Estes pacotes preservam fontes e ajustes do projeto para trabalho posterior; não representam renders, combinações ou animações visualmente aprovados.

- Capacetes: 362 registros de ajustes e 128 PNGs originais.
- Cabelos: 27 registros de ajustes e 94 PNGs originais.

Os registros técnicos mantêm seus valores originais. Metadados privados e relatos foram removidos. Os catálogos de contexto também podem conter estados sem ajuste fornecido; sua presença não implica aprovação. Cada ZIP explica o escopo e contém hashes de seus arquivos.

Nenhuma integração, renderização nova ou alteração do jogo é feita por este arquivo. Não entra na distribuição Pages. O índice de arte aprovada não inclui estes pacotes.
