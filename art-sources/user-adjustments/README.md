# Capacetes e cabelos: fontes e configurações prontas

Quatro pacotes preservam as artes e os ajustes fornecidos para feminino e masculino, autorizados pelo usuário para organização na branch.

- Feminino: 362 ajustes de capacetes e 27 de cabelos; 222 entradas PNG nos dois pacotes.
- Masculino: 408 ajustes de capacetes e 40 de cabelos; 246 entradas PNG nos dois pacotes.
- Todos os 837 targets foram ligados aos respectivos catálogos. Os 96 valores hideHair=true e todos os demais valores de ajuste foram preservados.

Os ZIPs mantêm seus nomes source-only para indicar o formato de entrega: fontes editáveis, não sprites finais integrados. Nenhum ajuste foi aplicado ao runtime do jogo, nenhuma combinação nova foi renderizada e os arquivos não entram na distribuição Pages. Os PNGs de contexto podem se repetir entre pacotes.

Os cabelos masculinos preservam identidades históricas de packs conforme o catálogo original: não são apresentados como hashes canônicos do conteúdo embutido atual. O catálogo e as correspondências dos 40 ajustes foram verificados. Os detalhes técnicos e hashes constam em cada pacote.
